HOW TO CHANGE ANY PHOTO ON THE WEBSITE
--------------------------------------
1. Pick the photo you want to change from the list below.
2. Rename your new photo to EXACTLY that file name.
3. Drop it into this folder (public/photos/).
4. git add public/photos && git commit -m "new photos" && git push

That's it. No code changes needed.
Bas file ka naam same rakhna hai — baaki sab apne aap ho jayega.

RECOMMENDED SIZES
-----------------
  hero.jpg ........ 1920 x 1080 px (landscape)
  all others ...... 1400 x 900 px  (landscape)
  logo.png ........ 400 x 400 px   (square, transparent background)

  Keep each file UNDER 500 KB so the website loads fast.
  Free compress tool: https://squoosh.app


IMPORTANT NOTES
---------------
* File names are case-sensitive. Use lowercase exactly as shown.
* .jpg and .png both work, but keep the name identical
  (e.g. if you have a PNG, still name it "hero.jpg" — browsers
  read the actual image, not the extension).
* If a file is missing here, the website automatically falls back
  to the original photo from the GitHub repo. Nothing will break.
* You can also change photos from the Admin Panel (Photos tab),
  but those only show on YOUR device until you publish.
  Dropping files HERE is the permanent way — sabko dikhega.
